# Rastreador de Despesas

Uma aplicação web responsiva para acompanhar um orçamento e organizar despesas
por categoria.

O projeto permite definir o orçamento disponível, adicionar e remover despesas
e consultar estatísticas como total gasto, despesa média, saldo, maior categoria
e totais por categoria. Os dados são mantidos no navegador para permanecerem
disponíveis após recarregar a página.

## Tecnologias e técnicas utilizadas

- HTML5 semântico
- CSS3
- JavaScript
- Metodologia BEM
- Flexbox e CSS Grid
- Media queries para layouts de desktop, tablet e celular
- Manipulação do DOM e eventos de clique e envio de formulário
- Elemento `template` para criar itens de despesa dinamicamente
- Cálculos de orçamento, saldo, média e despesas por categoria
- Armazenamento local com `localStorage`
- Fontes carregadas localmente com `@font-face`
- Ícone SVG e normalização de estilos com Normalize.css
